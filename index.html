ndhmd 웹 작업대

마크다운 원고를 브라우저에서 쓰고, .tex과 HTML로 바꾸고, 필요하면 내 컴퓨터의 LaTeX으로 PDF까지 만드는 작업대입니다.

로컬 TeX 없이 맛보기

설치할 것이 없습니다. 원고를 쓰고 .tex과 HTML로 바꿔 보는 데까지 되고, PDF 컴파일은 빠져 있습니다.

맛보기로 열기

웹앱 열기

PDF 컴파일과 PDF 보기, PDF와 원고 사이의 되짚기까지 쓰려면 이쪽입니다. 로컬 에이전트가 필요합니다(아래 안내).

웹앱 열기

버전 0.1 · 두 단추 모두 새 탭에서 열립니다. 맛보기에서 만든 작업은 전체 기능으로 열어도 그대로 이어집니다.

브라우저만으로 되는 것 (맛보기도 같습니다)

  • 원고 작성, 서랍(여러 파일을 {{파일}}로 묶는 구조), 목차, 점검
  • ndhmd4tex으로 .tex 변환, ndhmd2html로 HTML 변환 — 변환기가 브라우저 안에서 돌아가므로 원고가 서버로 가지 않습니다
  • 원고·그림·zip 올리기, zip으로 내보내기. 작업 내용은 이 브라우저에만 저장됩니다

PDF 컴파일은 로컬 에이전트가 합니다

PDF는 내 컴퓨터에 설치된 TeX(latexmk)로 만듭니다. 웹앱이 .tex을 보내면 작은 로컬 에이전트가 컴파일해서 PDF를 돌려줍니다. 에이전트는 이 컴퓨터(127.0.0.1)에서만 듣고, 연결 코드와 허용한 출처가 맞는 요청만 받습니다.

  1. Node.js 18 이상과 TeX Live(또는 MiKTeX)를 준비합니다.
  2. ndhmd-agent.mjs를 내려받습니다. (사용 설명서)
  3. 아래 명령으로 시작합니다. 이 사이트의 주소가 이미 들어 있습니다. 
    node ndhmd-agent.mjs --origin …
  4. 에이전트가 보여 주는 연결 코드를 웹앱의 설정 ▸ 로컬 에이전트에 넣고 연결합니다. 연결 코드는 처음 한 번 만들어져 저장됩니다.

Chrome과 Edge는 이 사이트가 내 컴퓨터에 연결하는 것을 처음 한 번 물어봅니다. 허용하면 됩니다. Safari처럼 막는 브라우저에서는 에이전트가 앱을 직접 내주는 방식(--app)을 쓰십시오. 자세한 내용은 사용 설명서에 있습니다.

알아 둘 점

  • 변환 엔진(Pyodide)과 PDF 보기(PDF.js)는 인터넷에서 받아 옵니다. 처음 한 번은 시간이 걸립니다.
  • URL로 준 그림은 PDF를 만들 때 로컬 에이전트(0.2 이상)가 대신 내려받습니다. 맛보기에는 에이전트가 없으므로, 그림을 받아서 올리고 원고의 주소를 파일 이름으로 바꾸십시오. HTML 변환에서는 URL 그림이 그대로 보입니다.
  • 브라우저 저장소를 지우면 작업 내용이 사라지니, 가끔 zip으로 내보내 두십시오.
